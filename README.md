# Лабораторная 1

Эта лабораторная состоит из 1 задания.

### Общая структура лабораторных

Все задания описаны в корневом файле `README.md`.

Ваши решения вы публикуете в этом же репозитории.

Для каждого задания вы создаете папку `task-XX`, где `XX` - номер задания (возможно, начинающееся с 0).
В эту папку вы складываете все файлы, относящиеся к решению. Как правило, это будет bash скрипт с названием `solution.sh`.
Решения проверяются автоматически, поэтому важно соблюдать структуру проекта.

Ваши решения будут запущены в Docker-образе, подготовленном для этой лабораторной.
Если вы хотите прогнать свой скрипт у себя локально в том же окружении, изучите файл с конфигурацией GitHub Actions
для проверки вашей лабораторной, и подтяните соответствующий образ.
